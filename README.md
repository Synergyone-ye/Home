# سِينرجي ون | Synergy One — رِكاز للمحاسبة والإدارة وحلول الأعمال

منصة متكاملة وحديثة لشركة **سِينرجي ون (رِكاز)** المتخصصة في التدقيق المالي، المراجعة الخارجية، مسك الحسابات، التحول الرقمي وأنظمة ERP، ودراسات الجدوى.

---

## 🚀 جاهز للنشر الفوري على GitHub Pages

تم تجهيز هذا المشروع وتطويره ليكون متوافقاً تماماً مع **GitHub Pages**:
1. **مسارات نسبية مرنة**: تم ضبط `base: './'` في `vite.config.ts` لضمان عمل الموقع حتى لو نُشر تحت اسم مستودع فرعي مثل `username.github.io/repo-name/` أو نطاق خاص `domain.com`.
2. **تخطي معالجة Jekyll**: تم إضافة ملف `public/.nojekyll` لمنع تجاهل الملفات والمجلدات أثناء النشر.
3. **التوجيه الأحادي (SPA Fallback)**: تم تجهيز `public/404.html` لإعادة التوجيه السلس إلى الصفحة الرئيسية.
4. **أتمتة النشر عبر GitHub Actions**: يوجد ملف سير عمل جاهز ومضبوط في `.github/workflows/deploy.yml` ليقوم ببناء ونشر الموقع تلقائياً بمجرد عمل `git push`.

## 📋 خطوات النشر على GitHub Pages

### الطريقة الأولى: النشر التلقائي عبر GitHub Actions (موصى بها)
1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً: `synergy-one`).
2. افتح موجه الأوامر في مجلد المشروع وقم بتنفيذ الأوامر التالية:
```bash
git init
git add .
git commit -m "feat: launch Synergy One platform"
git branch -M main
git remote add origin https://github.com/<اسم_المستخدم>/<اسم_المستودع>.git
git push -u origin main
```
3. توجه إلى المستودع على GitHub:
   - اضغط على **Settings**
   - اختر **Pages** من القائمة الجانبية
   - في قسم **Build and deployment**، اختر المصدر: **GitHub Actions**
4. سيعمل سير العمل تلقائياً ويصبح موقعك متاحاً على الرابط:
   `https://<اسم_المستخدم>.github.io/<اسم_المستودع>/`

## ✨ المميزات الرئيسية للموقع
- **خلفية تفاعلية ثلاثية الأبعاد (Three.js)**: مجسم مالي متطور وحلقات مدارية وسحابة جزيئات بيانات تدور وتتفاعل مع حركة الماوس واللمس.
- **منظومة الخدمات التسع المتخصصة**: مع ميزة الفلترة السريعة وتفاصيل كاملة للنطاق والمخرجات والفوائد لكل خدمة.
- **حاسبة الوفر المالي والعائد (ROI Calculator)**: تتيح لرواد الأعمال حساب التكلفة السنوية التقديرية ومقدار الوفر مقارنة بتوظيف كوادر داخلية.
- **مقياس الجاهزية الإدارية والمحاسبية**: استبيان تفاعلي وسريع يُشخص وضع المنشأة ويولد توصية مباشرة عبر واتساب.
- **تواصل متعدد القنوات فوري**: واتساب مباشر، نسخ بنقرة واحدة للبريد الرسمي، نموذج طلب استشارة، وروابط وسائل التواصل.
- **تصميم عصري فائق السرعة**: مبني بـ React 19، Tailwind CSS v4، ودعم كامل للغة العربية والاتجاه RTL وخطوط Cairo و Tajawal.
